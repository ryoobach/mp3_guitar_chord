# MP3 기타 코드

MP3 음악을 재생하면서 기타 코드를 실시간으로 표시하는 안드로이드 앱입니다.

## 주요 기능

- MP3 파일 재생
- Winamp 스타일의 플레이어 화면
- 음악 재생 시간 표시
- 재생 위치에 맞춰 기타 코드 스크롤 표시
- 현재 재생 중인 코드 강조
- 원음 그대로 재생 및 볼륨 조절
- 백그라운드 음악 재생
- 자동 기타 코드 분석 (추후 구현)
- 노래 가사 자동 추출 및 표시 (추후 구현)

## 개발 환경
- Android
- Kotlin
- GitHub Actions
